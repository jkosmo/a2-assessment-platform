# Workflow: a course from documents, notes, web sources or the author's own words

Use this when the source is text. When it is a PowerPoint presentation, use
[from-presentation.md](from-presentation.md) instead.

Stop at every gate and wait for the author.

## Gate 1 — Source

Establish what the course is built on before you propose anything.

1. Ask what the course should be based on:
   - **material the author uploads or pastes** (a policy, a report, notes, a transcript) — preferred;
   - **web sources** — search, then show what you found (title and what each covers) and let the
     author choose which to use;
   - **the author's own account** of the subject.
2. If there is no material and the author does not want to supply or search for any, say so and
   offer the unverified draft: *"Jeg har ikke noe kildemateriale å bygge på. Vil du at jeg lager et
   ubekreftet utkast fra allmenn kunnskap som du selv må verifisere? Alt vil bli merket
   [Avklaring]."* Go on only on a clear yes.
3. Write down the confirmed sources. They go into the package at gate 6, and the independent check
   at gate 5 reads them again.

## Gate 2 — Learning objectives

Propose 3–6 objectives drawn from the source, each as "Etter dette kan deltakeren …", and confirm
the course's language. How: [course-design.md](../references/course-design.md#learning-objectives).

## Gate 3 — Structure

Propose the outline as a table: sections and modules in order, the test form of each module, which
objective each one serves, and the level. How:
[course-design.md](../references/course-design.md#structure).

Say in the same table what each section will **show**, not only what it will say:

- A table, a figure or a picture in the source is carried over. Leaving one out is a choice you
  state, with the reason.
- Where the source describes a sequence, a comparison, a set of parts or a set of alternatives in
  running text, propose the form that shows it: a figure, a table, cards or a highlighted box
  ([section-content.md](../references/section-content.md),
  [figure-design.md](../references/figure-design.md#which-form)).
- A prompt, a template or an example the learner is meant to reuse gets its own box, so it can be
  copied.

## Gate 4 — Each element

One section or module per turn, approved before the next.

- **A section:** the text, written from the source, with its figures, tables, boxes and pictures
  in place — shown together, because they are approved together. Write it to its own file,
  `work/sections/<clientRef>.nb.md`, and add it to `work/package.json` as you go
  ([package-schema.md](../references/package-schema.md)). Until gate 6 the package holds the
  course's one language only.
  [section-content.md](../references/section-content.md),
  [figure-design.md](../references/figure-design.md).
- **A module:** the task, the assessment criteria and the questions.
  [modules.md](../references/modules.md).

After each approval, store the element in full: [content-preservation.md](../references/content-preservation.md).
